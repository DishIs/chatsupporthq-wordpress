# ChatSupportHQ for WordPress

WordPress plugin that adds the ChatSupportHQ chat widget and AI agent to any WordPress site.

Part of [ChatSupportHQ](https://chatsupporthq.com): AI chat support for websites, with unlimited seats and flat pricing. The API, SDKs, CLI and MCP server are included on the free plan.

> **Status:** in active development. The first release is planned for December 2026. Watch this repo for releases.
